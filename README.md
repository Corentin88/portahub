# PortaHub — Site vitrine

Site vitrine responsive en **HTML, CSS et JavaScript natif**, conçu pour accompagner un pitch de cinq minutes selon la méthode **APB**.

## Ouvrir le site

Double-cliquer sur `index.html` ou utiliser l’extension **Live Server** dans VS Code / Antigravity IDE. Aucun framework, aucune compilation et aucune installation ne sont nécessaires.

## Fichiers

- `index.html` : structure et contenu, sections APB, appel à l’action.
- `styles.css` : mise en page responsive, cabine illustrée uniquement en CSS, animations.
- `script.js` : menu mobile, apparition au défilement, barre de progression, formulaire de démonstration.

1. **Accroche** (intervenant 1) : section d’accueil, promesse de supprimer le temps de trajet (environ 1 min).
2. **Problème** (intervenant 2) : la section « Le constat » (environ 1 min 15).
3. **Bénéfices et solution** (intervenant 3) : « La technologie », « Les bénéfices » et « Notre vision R&D » (environ 2 min).
4. **Conclusion** (les trois) : « Rejoindre la bêta » (environ 45 s).

## Note importante

**PortaHub est fictif.** La téléportation humaine et les dispositifs annoncés ne sont pas démontrés. Les chercheurs sont des personnages fictifs, les 50 cabines appartiennent au scénario, et le formulaire n’envoie aucun e-mail. Les estimations sont présentées comme hypothèses ou ordres de grandeur : vérifiez-les avant toute utilisation comme faits publics.
